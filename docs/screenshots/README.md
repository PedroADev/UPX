# Capturas reais — Ilha do Saber

Imagens produzidas na Unity 6000.0.83f1, em Play Mode, pela renderização da Game View com interface UI Toolkit. Resolução: 1280 × 800. O cenário usa os prefabs originais do Toon Environments — World Creator Pack Lite, com a textura Spring.

Rodada final: `demo-20261015-194448-717`. O modo exibido é prática; não há colegas simulados. O personagem foi deslocado pelo controlador real do jogo e a primeira resposta foi corrigida pelo serviço de prática. O perfil e a seleção anterior da Game View são restaurados após a demonstração.

O [manifest da execução](demo-20261015-194448-717/manifest.json) registra posições, entrada de movimento, frames, dimensões verificadas dos PNGs, resultado da resposta, logs e restauração do estado do Editor. Pastas de rodadas anteriores preservam a evolução da revisão visual.

Para repetir, use **Ilha do Saber > Capturas > Capturar demonstração completa**, com o Editor fora do Play.
